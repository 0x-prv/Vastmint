# VastMint

The native NFT marketplace and launchpad built for Ritual.

VastMint enables creators to launch NFT collections, mint digital assets, and trade NFTs through a modern and seamless experience powered by Ritual infrastructure.

## Features

- NFT Marketplace
- Collection Launchpad
- Dynamic Collection Deployment
- NFT Minting
- Buy, List, and Cancel Listings
- Collection Pages and NFT Details
- Wallet Integration
- IPFS Metadata Storage
- Responsive UI
- Modern Web3 Experience

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Solidity
- Hardhat
- Wagmi
- Viem
- RainbowKit
- Pinata IPFS

## Ritual Skills Used

This project leverages Ritual's AI-assisted development workflow:

- **use-wallet** – wallet connection and account management
- **use-contracts** – smart contract interactions
- **use-events** – reading marketplace and mint events
- **use-viem** – transaction execution and blockchain clients
- **use-hardhat** – contract deployment and testing
- **use-nextjs** – frontend architecture and routing
- **use-typescript** – type-safe development
- **use-tailwind** – responsive and modern UI development
- **use-ipfs** – decentralized NFT metadata storage

## Smart Contracts

### VastMintNFT
ERC-721 contract for NFT collections and minting.

### VastMintFactory
Deploys and manages creator collections.

### VastMintMarketplace
Handles NFT listings, purchases, and cancellations.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/0x-prv/VastMint.git
cd VastMint
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
